# Schemas

The schemas are exploratory and use JSON Schema Draft 2020-12 expressed as YAML.

Current experimental artifacts:

- `datagovops-public-sector-profile.schema.yaml`: data-product governance profile;
- `information-product-profile.schema.yaml`: proposed technology-independent
  information-product layer and links to technical realizations.

Naming convention:

- `*.schema.yaml`: machine-readable schemas;
- released schemas will use semantic versions;
- experimental identifiers use `v0alpha1`.

A schema can validate representation and internal consistency. It cannot
independently establish legal, archival or organizational compliance. The
information-product schema is an executable design hypothesis, not an adopted
standard.
