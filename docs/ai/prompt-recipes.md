# Prompt recipes

These are examples for people, not deprecated Codex custom-prompt files.

## Add a source

> Use the add-authoritative-reference skill to verify DCAT-AP-SE 3.0.1, register it, and explain which profile decisions
> it can support.

## Review a schema change

> Use source_verifier and archival_governance_reviewer to review the proposed retention metadata independently. Then
> use review-profile-change to consolidate findings. Do not edit until the evidence gaps are clear.

## Plan a cross-cutting change

> Create an ExecPlan for adding machine-readable arkivredovisning metadata. Separate legal requirements, guidance,
> interpretations and proposed profile fields. Include compatibility and evaluation plans.

## Validate

> Use validate-datagovops-repository after the change. Report syntax and schema coverage separately from compliance
> claims.
