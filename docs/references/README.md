# Reference register

Record each external source with:

- exact title and issuing organization;
- version or publication date;
- stable URL or identifier;
- access date;
- source type: legislation, regulation, guidance, standard or research;
- normative status;
- requirements or design rationale derived from it;
- interpretation notes and open questions.

Do not add a requirement to the profile without traceability to a source or an explicitly marked design hypothesis.
