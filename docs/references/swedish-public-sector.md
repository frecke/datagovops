# Swedish public-sector sources

## Binding sources

- [Arkivlag (1990:782)](https://www.riksdagen.se/sv/dokument-och-lagar/dokument/svensk-forfattningssamling/arkivlag-1990782_sfs-1990-782/)
- [RA-FS 2009:1](https://foreskrifter.riksarkivet.se/rafs/105)

Binding status never removes the need to verify scope, amendments, current wording and applicability.

## National specifications and guidance

- [DCAT-AP-SE 3.0.1](https://docs.dataportal.se/dcat/3.0.1/en/)
- [DIGG: Vägledning för att tillgängliggöra information](https://www.digg.se/kunskap-och-stod/oppna-och-delade-data/vagledning-for-att-tillgangliggora-information)
- [DIGG: Svenskt ramverk för digital samverkan](https://www.digg.se/kunskap-och-stod/regler-och-rekommendationer/regler-och-rekommendationer/anvand-svenskt-ramverk-for-digital-samverkan)
- [Riksarkivet: Föreskrifter och vägledningar](https://riksarkivet.se/arkivera-och-forvalta/foreskrifter-och-vagledningar)
- eSam ES2025-01, *Digitalt bevarande av data - problemområden*
- eSam ES2024-15, *Roadmap för myndigheters datahantering*

Guidance can motivate design objectives and evaluation criteria. It must not silently be converted into a legal
obligation.

## Working questions

- Which metadata requirements are directly binding for the intended authority and information type?
- Which are recommendations, capability goals or design proposals?
- How should public-record status, archival status and preservation readiness be represented without conflation?
- Which decisions require an archivist, records manager, lawyer or information-security specialist?
- How are arkivredovisning, classification structure and system-of-record responsibilities linked to a data product?
