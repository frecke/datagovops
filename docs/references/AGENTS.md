# Reference instructions

- Use primary or authoritative sources whenever available.
- Record exact source identity, issuer, version or date, URL, access date and normative status.
- Never infer a legal obligation from guidance without marking the interpretation.
- Never treat a search result snippet as the source. Open and inspect the source itself.
- Mark living pages and drafts as time-sensitive.
- For superseded material, retain the historical entry and add its replacement relationship.
- Keep source metadata in `source-register.yaml`; keep derived requirements in separate traceability artifacts.
- Do not copy substantial copyrighted text. Summarize and link unless reuse is clearly licensed.
