# Roadmap

## 0.1 Foundation

- Establish vocabulary and source register.
- Pin exact versions of ODCS, ODPS, DCAT-AP-SE and Swedish guidance.
- Separate normative requirements from proposed profile design.
- Define schema versioning and compatibility policy.

## 0.2 Public-sector profile

- Map governance, semantic, archival and provenance concerns.
- Implement representative fictional examples.
- Add conformance fixtures and validation tests.
- Review with domain experts.

## 0.3 Evaluation

- Define traceable evaluation criteria.
- Demonstrate the artifact in a realistic, anonymized case.
- Publish limitations and unresolved legal or standards questions.

Runtime enforcement and OPA/Rego policy packs are intentionally deferred to later work.
